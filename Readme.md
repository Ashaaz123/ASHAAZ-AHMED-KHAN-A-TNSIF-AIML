# TNS India Foundation – AIML Training Repository

## About This Repository

This repository contains my **daily coding problems, assignments, practice exercises, and machine learning projects** completed as part of the **Artificial Intelligence and Machine Learning (AIML) Training Program conducted by TNS India Foundation**.

The repository is maintained throughout the training period to document my **learning progress, practical implementations, and hands-on experience** with programming, data analysis, machine learning, and related concepts.

The work in this repository includes both **individual practice tasks and structured training assignments**.

The primary objectives of this training are to:

# 🤖 3. Supervised Learning

This section contains machine learning assignments based on **Supervised Learning**.

The models are trained using labelled datasets where the target/output variable is known.

### Algorithms Practiced

#### Linear Regression

Used for predicting continuous numerical values.

Example:

**Years of Experience → Salary**

#### Logistic Regression

Used for binary classification problems.

Example:

**Age + Income → Product Purchase**

#### Decision Tree

Used for classification by learning decision rules from the training data.

Example:

**Age + Income → Product Purchase**

#### Random Forest

Used for classification by combining multiple decision trees.

Example:

**Age + Tenure + Monthly Bill → Customer Churn**
