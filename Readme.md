## 🔎 12. Embeddings & Retrieval-Augmented Generation (RAG)

Exploring how relevant external information can be retrieved and supplied to a language model when answering a question.

**Concepts explored:**
- 📝 Document preparation and chunking
- 🔢 Text embeddings
- 🔍 Semantic similarity
- 📐 Cosine similarity
- 🗂️ Document retrieval
- 🧠 Context-aware text generation
- 🗄️ Vector database concepts
- 🔗 Retrieval-Augmented Generation

### ⚙️ Practical RAG-Style Implementation

The Python exercise uses Sentence Transformers to represent documents and a query as embeddings, then retrieves the most similar document using cosine similarity.

The retrieved information is supplied to a pretrained text-generation model to generate a response.

```text
📄 Documents
      ↓
🧹 Preparation
      ↓
🔢 Text Embeddings
      ↓
❓ User Question
      ↓
🔍 Similarity Search
      ↓
📚 Retrieved Context
      ↓
🤖 Language Model
      ↓
💬 Generated Answer
```

🛠️ **Technologies:** Sentence Transformers · Transformers · PyTorch

*The current implementation demonstrates a basic RAG-style workflow using sample documents and similarity search; it does not require a separate vector database.*
